# 入出庫履歴の返品相殺・商品一覧の価格表示調整計画

## 目的

- 入出庫履歴で返品を独立した作業内容として表示せず、販売数量と原価合計へ相殺する。
- 商品マスタ検索結果で価格を確認しやすくし、粗利率の代わりに税込価格を表示する。

## 変更方針

1. 選択期間・店舗・同一商品ごとに、販売数量と返品数量を集計する。
2. 返品がある商品だけ販売と返品を1件へまとめ、販売数・原価合計から返品分を差し引く。
3. 相殺後の販売数量が0以下なら、その商品の販売・返品行を表示しない。
4. 注文、店舗間移動、物品使用など、販売・返品以外の履歴はそのまま保持する。
5. 商品一覧の列順を「JAN、商品情報、価格、仕入れ先、店舗、状態、更新日、操作」に変更する。
6. 粗利率を削除し、`売価 + 切り捨て(売価 × 10%)`で税込価格を表示する。

## テストケース

- 販売2個・返品1個は販売1個として表示する。
- 販売1個・返品1個は表示しない。
- 返品が販売を上回る場合は表示しない。
- 返品のない販売行と販売・返品以外の履歴は変更しない。
- 売価980円は税込1,078円、端数が出る場合は税額を切り捨てる。
- 価格列が仕入れ先列より左にあり、粗利率が表示されない。
