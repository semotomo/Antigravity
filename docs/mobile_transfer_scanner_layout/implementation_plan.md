# 商品移動・スマホ連続スキャン画面 改善計画

## 目的

- スマホでスキャン商品リストをできるだけ広く表示する。
- 連続スキャン中の商品リストを指で縦スクロールできるようにする。
- 通常のJAN入力画面とPC表示の既存動作を維持する。

## 変更方針

1. 連続スキャン中のモーダルを、スマホでは動的ビューポート高いっぱいに広げる。
2. ヘッダー、完了ボタン、読取案内を小型化し、スキャン画面までの余白を除去する。
3. 連続スキャン中だけJANコード見出しを表示しない。
4. 商品リストの固定高と縮小禁止指定を外し、スキャン画面以外の残りの高さを割り当てる。
5. 商品リスト内にタッチ向けの縦スクロールとオーバースクロール制御を設定する。
6. 共通JANスキャナーの小型表示は任意プロパティとし、既存利用箇所へ影響させない。

## 検証

- 修正前に失敗する表示構造の回帰テスト
- 商品移動フォームの既存離脱警告・並び順テスト
- 店舗別商品分離テスト
- TypeScript型検査
- 変更ファイルのESLint
- Next.js本番ビルド
- Vercel Productionデプロイ状態
