# 商品移動フォームの離脱警告・並び順修正計画

## 目的

- 新規登録の入力や登録リストが残っているとき、スマホ下部タブを含むページ移動で内容を失わないようにする。
- 新しく追加した商品を登録リストの上に表示する。

## 変更方針

1. 未保存状態のときだけ、画面内リンクのクリックとブラウザ離脱を監視する共通フックを追加する。
2. 移動をキャンセルした場合はイベントを停止し、現在のモーダルと入力内容を保持する。
3. 商品マスタ一致、手入力、未一致解消の各追加経路で新規行を配列先頭へ追加する。
4. 同一条件の商品を再読取した場合は既存行の数量だけを加算する。

## 検証

- 回帰テスト
- TypeScript型検査
- 変更箇所のESLint
- Next.js本番ビルド
- スマホ幅の下部タブ遇移の確認
